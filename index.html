DYFood Calendar

개인용 바탕화면 캘린더입니다. 사용자 본인의 Google 캘린더 일정을 본인 PC 바탕화면에 보여 주고, 사용자 본인이 허락한 사람에게만 함께 보여 줄 수 있습니다. 판매하거나 일반에 배포하지 않습니다.

A personal desktop calendar widget. It shows the user's own Google Calendar events on the user's own PC, and may also show them only to people the user has explicitly permitted. It is not sold or distributed to the public.

개인정보처리방침 / Privacy Policy

  • Google 캘린더 일정을 읽기만 합니다(calendar.readonly). 일정을 만들거나 고치거나 지우지 않습니다.
  • 가져온 일정과 로그인 토큰은 사용자 본인 PC에만 저장됩니다.
  • 일정은 사용자 본인의 PC 화면에, 그리고 사용자 본인이 허락한 사람에게만 보여 줄 수 있습니다. 그 밖의 외부 서버나 제3자에게는 보내지 않습니다.
  • 광고, 분석, 판매에 쓰지 않습니다.
  • Google 사용자 데이터의 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
  • 권한 철회: Google 계정 → 타사 연결에서 언제든지 취소할 수 있고, PC에 저장된 데이터는 프로그램 폴더를 지우면 함께 삭제됩니다.
  • Read-only access to Google Calendar (calendar.readonly); events are never created, changed or deleted.
  • Events and tokens are stored only on the user's own PC.
  • Events are shown on the user's own PC and only to people the user has explicitly permitted. They are never sent to any other server or third party.
  • No advertising, analytics or sale of data.
  • Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.
